# CEO skills

A CEO plus four role workers, all run from one Claude Code session.

- **CEO**: the session you talk to. It hands jobs to the workers and reports back.
- **writer, research, design, review**: role files in `.claude/agents/`.

## Use it
1. Put this folder's `.claude` directory in your project folder.
2. Start a new Claude Code session in that folder.
3. Tell the session the job; it delegates to the roles by name.
